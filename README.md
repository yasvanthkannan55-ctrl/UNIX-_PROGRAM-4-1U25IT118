# Linux Practical – Create a File Using touch

## Aim

To create a file on a Linux machine using the `touch` command.

## Objective

Students should learn how to:

1. Create an empty file using the `touch` command.
2. Create multiple empty files using one `touch` command.
3. Verify created files using the `ls` command.
4. Submit the practical program through GitHub.
5. Understand automated testing using GitHub Actions.

---

## Algorithm

### Step 1
Open the Terminal on a Linux machine.

### Step 2
Use the `touch` command to create a file.

### Step 3
Create multiple empty files at once by specifying the filenames separated by spaces.

Example:

```bash
touch file1.txt file2.txt file3.txt
